# Sigilo en la ciudad

Juego 3D de sigilo y parkour ambientado en una ciudad florentina de 1478, inspirado en Assassin's Creed II. Está pensado para un niño con movilidad muy limitada y se controla con dos zonas de contacto, izquierda y derecha. Tocar ambas a la vez significa "recto".

Es un único archivo, `index.html`, hecho con Three.js r128. Se abre directamente en el navegador.

## Cómo jugarlo
- Abre `index.html` en Chrome, Safari o Edge. En iPhone o en un computador con pantalla táctil funciona con las zonas de contacto.
- También se puede publicar con GitHub Pages: Settings → Pages → rama `main`, carpeta raíz.

## Opciones para adultos
El panel de adultos permite ajustar, entre otras cosas:
- Escalada libre
- Ayuda de rutas
- Cámara cinematográfica
- Velocidad, calidad gráfica y volumen
